## 1. Mô tả hệ thống
Hệ thống quản lý nhân sự cho phép người dùng xem danh sách, thêm mới, tìm kiếm, cập nhật và xóa hồ sơ nhân viên.

## 2. Công nghệ sử dụng
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB Atlas
- Containerization: Docker, Docker Hub
- Deployment: Render

## 3. Hướng dẫn chạy ứng dụng ở môi trường phát triển (Local)
- Clone repository: `git clone https://github.com/thanhbao237502-png/237502_TranThanhBao.git`
- Chạy Backend: `cd backend && npm install && npm start`
- Chạy Frontend: `cd frontend && npm install && npm start`
